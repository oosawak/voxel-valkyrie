# Voxel Valkyrie — 3-Form Transformation & Aerial Combat Simulator

3Dボクセル（Three.js）および 2.5D Sprite Stacking 描画で、ファイター・ガウォーク・ロボットの3形態へリアルタイム変形しながら大空戦を楽しめるブラウザゲーム＆変形シミュレーターです。

## 同梱ファイル構成

- `index.html` — シミュレーター＆空戦ゲーム本体（単体動作）
- `README.md` — 操作説明・機能紹介
- `.nojekyll` — GitHub Pages の Jekyll 処理をスキップして高速配信するための設定ファイル
- `.github/workflows/deploy.yml` — `main` ブランチへの push 時に自動デプロイする GitHub Actions 設定

## 操作方法

| キー / 操作 | 機能 |
| :--- | :--- |
| **`1` / `2` / `3`** | ファイター / ガウォーク / ロボットへ変形 |
| **`Tab`** | 3形態を順番に変形 |
| **`W` / `S`** | ピッチ操作（機首上下・前進/後退） |
| **`A` / `D`** | ロール旋回・左右ストレイフ |
| **`Shift`** | アフターバーナー / ブースト加速 |
| **`Space` / 左クリック** | メイン武装発射（バルカン / 3WAYガンポッド / ビームライフル） |
| **`E` / 右クリック** | サブ武装発射（誘導ミサイル / 一斉射撃） |
| **マウスドラッグ / ホイール** | カメラ回転・ズーム |

## GitHub Pages 公開手順

1. GitHub で新しいリポジトリを作成します。
2. 本 ZIP を解凍したファイル一式をリポジトリのルートに配置し、`main` ブランチへプッシュします。
3. GitHub Actions が自動実行され、数分後に `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開されます。
